# rijdoujin_qmt

把 **竞价分析 App 的早盘集合竞价选股结果**，通过本机 HTTP 通道送进 **QMT**，
在 09:30 自动买入、次日 14:50 自动清仓，并提供一个 **每秒刷新** 的 HTML 运行看板。

> ⚠️ 本项目是个人量化研究工具，**不构成任何投资建议**。回测/实盘均有亏损风险，务必先用 `DRY_RUN` 空跑。

---

## 为什么需要它

QMT 的策略沙箱**禁止读写本地文件**（`Forbidden fileIO`），但**允许网络访问**。
所以外部数据（选股结果）不能用"写文件→策略读文件"的方式进入 QMT，
必须走一条 HTTP 通道：

```
选股结果 → 本机服务（127.0.0.1:8765）→ QMT 策略 HTTP GET → 下单
```

这条通道实测有效，且策略可以每秒轮询，天然带心跳。

## 快速开始

### 0. 准备

- Windows + QMT 交易端（国金/迅投系），能登录
- 竞价分析 App 每天导出的 `竞价数据_YYYY-MM-DD.csv`
- Python 3.6+（可直接用 QMT 自带的 `pythonw.exe`）

设置两个环境变量（不改也能跑，默认值是占位路径）：

```powershell
setx QMT_DIR        "D:\你的QMT安装目录"
setx JJB_EXPORT_DIR "F:\你的导出目录"
```

### 1. 启动名单服务

```powershell
D:\...\bin.x64\pythonw.exe server\list_server.py
```

浏览器打开 <http://127.0.0.1:8765/> 看到看板即成功。

### 2. QMT 里建两个策略

`模型研究 → +新建策略 → Python策略`，分别粘贴 `qmt/autobuy_from_list.py`
和 `qmt/autosell_close.py`，保存 → 编译 → 在「模型交易」里启动。

### 3. 推送今日名单

```powershell
pythonw feeder\push_from_export.py --dry   # 先看会选哪些票
pythonw feeder\push_from_export.py         # 真推送
```

### 4. 一键启动 + 监控

```powershell
tools\启动.bat            # 拉起缺的模块 + 打印一次状态
tools\启动.bat -Watch     # 终端里持续刷新
tools\启动.bat -Board     # 打开 HTML 看板
tools\启动.bat -SetupTask # 安装每天 09:29:40 的推送计划任务
```

|---|---|---|

## 接口

| 接口 | 说明 |
|---|---|
| `GET /today.csv` | 今日名单（逗号分隔，带 `.SH/.SZ` 后缀） |
| `GET /set?codes=...` | 推送名单（自动补全市场后缀） |
| `GET /hb?role=buy\|sell&n=N` | 策略心跳，看板据此判断存活（≤5s 为正常） |
| `GET /status` | 聚合状态 JSON（看板每秒拉取） |
| `GET /` | HTML 看板 |
| `GET /ping` | 存活探测 |

## 筛选规则（从 App 提取）

「高胜率」预设：

| 条件 | 值 |
|---|---|
| 竞价涨幅 | 2.0% ~ 4.0% |
| 涨停概率 | ≥ 60 |
| 可信度 | ≥ 70 |
| V2 评分 | ≥ 35 |
| 市值 | 30 ~ 200 亿 |
| 股价 | 5 ~ 60 元 |
| 剔除 | ST/停牌、`warnFlag ≥ 5` |
| 排序 | 概率降序（同分按评分、代码） |

评分/概率的完整公式与回归验证见 [docs/DESIGN.md](docs/DESIGN.md)：
**预设区间内与 App 输出 100% 一致**（57/57 概率、57/57 评分）。

### 三个已知实现缺陷（原样保留，仅记录）

1. **竞价换手率量纲错误** — 结果恒为 ~1e-6，权重 32% 的活跃度因子实际失效
2. **「剔涨停」判的是 `warnFlag ≥ 5`**，不是涨幅 ≥ 9.5%，触板但 warnFlag=4 的票仍会入选
3. **市值取导出时点**，与 09:25 评分时点不同，跨档会让概率差 1~4 分

## 推演结果（4 个交易日）

| 卖出口径 | 全市场 | 入选 | 超额 |
|---|---|---|---|
| 当日收盘（纸面，T+0 不可实现） | +0.92% | +0.43% | −0.49% |
| 次日开盘 | +0.73% | +0.91% | +0.18% |
| **次日收盘** | +1.21% | **+3.29%** | **+2.08%** |

样本仅 4 天（185 笔入选 / 1599 笔全市场抽样），且含普涨日，**该数字很可能被高估**。
这也是默认 `DRY_RUN = True` 的原因：先空跑 10~20 个交易日，用 `out/push_*.json` 统计真实表现。

## 安全与边界

- 所有通信仅限 `127.0.0.1`，不对外网开放
- 策略默认 `DRY_RUN = True`，只打印不下单
- 账户号不出现在代码里，由 QMT 的 `account` 全局变量注入
- 本仓库不含行情数据、不含账户凭据
