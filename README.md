# rijindoujin_qmt — 竞价选股 → QMT 自动交易（剪贴板通道）

QMT 2.1.36 的策略沙箱会阻断策略进程的网络访问（`[防外接] ...策略运行中止`）和文件 IO
（`Forbidden fileIO`），本机唯一可用的通道是 **Windows 剪贴板**。本项目就是把
「竞价选股 → 下单」整条链路跑通的那套东西。

```
东财竞价快照(push2dycalc)
        │  bid_fetch.py  (09:24:40 启动，09:25:00 抓取)
        ▼
bid_rules.py 预设筛选（涨幅 2–4%、概率、可信度、评分、市值、剔除 ST/停牌）
        │  写剪贴板：QMTCLIP1|yyyymmddHHMMSS|代码列表|签名
        ▼
QMT 策略 autobuy_clip.py（部署为 D:\国金QMT交易端模拟\python\竞价剪贴板买入.py）
        │  09:25:05 读剪贴板 → T1 形态闸门 → 挂限价（昨收+5%，封顶涨停价）
        ▼
passorder → 模拟柜台 → 成交
        │
        ▼
14:50 卖出当日可用持仓（指定价 = 昨收-5%，封顶跌停价）
```

## 目录

| 文件 | 作用 |
|---|---|
| `bid_fetch.py` | PC 端第一腿：抓竞价快照 → 预设筛选 → 推剪贴板 + 写审计 JSON |
| `bid_rules.py` | 选股规则（`HIGH_WIN_RATE` 预设、评分、概率、可信度） |
| `clip_push.py` | 手动推送：`--codes` 指定代码，或 `--file` 读 CSV（回放/测试） |
| `autobuy_clip.py` | **QMT 策略**：剪贴板买入 + 14:50 卖出，含 T1 形态闸门 |
| `pattern_filter.py` | T1 形态（涨停→回踩→吞金杀牛线突破）计算与 35 天回测 |
| `剪贴板通道.md` | **主文档**：通道设计、协议、回测结论、档 1+档 2 实现 |
| `使用手册.md` | 日常操作手册（部署、计划任务、排错） |
| `out/` | 每日抓取审计 `fetch_YYYYMMDD.json` |
| `_qmt_ref/` | 调试脚本、单测、策略备份（不入库缓存） |

`list_server.py` / `autobuy_from_list.py` / `autosell_close.py` 等是早期 HTTP 版，
已停用，仅作历史参考。

## 关键设计

- **载荷协议**：`QMTCLIP1|<时间戳>|<代码,代码,...>|<签名>`，签名 `h=7; h=(h*131+ord(c))&0xFFFFFFFF`，
  日期必须是当天，token 去重 → 同一份名单不会重复下单。
- **T1 形态闸门**：`X30=(MA5+..+MA30)/6`；近 10 日有涨停 → 突破 X30 → 回踩 X30 → 站上 X30 且不超 8%
  → X30 走平。只在命中 T1 时开仓，没有就空仓。
- **取价**：不再用 `get_full_tick`（策略里恒为空），统一用 `get_market_data_ex` 本地日线取昨收。
- **下单**：`passorder(23, 1101, acct, code, 11, 昨收×1.05, vol, ...)`，09:25:05 提交，
  券商暂存至 09:30 集中报单，抢在 09:30:00 下单之前。
- **卖出**：`passorder(24, 1101, ..., 11, 昨收×0.95, ...)`，比"最新价"更容易成交。

## 回测（35 个交易日，738 笔）

| 分组 | n | 平均（D 开→D+1 收） | 胜率 |
|---|---|---|---|
| 全部候选 | 738 | -0.43% | 43% |
| **T1** | 13 | **+3.69%**（超额 +5.49%） | 62% |
| T2 | 60 | +0.24% | 55% |
| T3 | 665 | -0.57% | 41% |

结论：**基准池子是负期望，T1 是唯一稳定为正的一层**（样本仍小，继续累积）。

## 运行环境

- Windows + QMT 2.1.36（国金证券模拟客户端，账号 63009312）
- 计划任务 `QMT竞价抓取`：每天 09:24:40 启动 `pythonw bid_fetch.py --watch`
- 策略部署：把 `autobuy_clip.py` 覆盖到 `D:\国金QMT交易端模拟\python\竞价剪贴板买入.py`，
  在「模型交易」里以 **实盘模式** 运行（策略文件必须是纯 ASCII，中文注释会导致 GBK 解码失败）
- 关闭 `DRY_RUN` 才会真实下单
